# Evan Austin, Portfolio

My personal portfolio site, live at [muuscodes.github.io](https://muuscodes.github.io/).

I'm an impact-driven software developer. After five years living in and working with underserved communities in West Africa, Central America, and South America, I build technology that empowers individuals and communities.

## Featured projects

- [Crossword Crew](https://www.crosswordcrew.com/): a social crossword creator
- [Sudoku App](https://sudoku-for-fun.netlify.app/): a sudoku game built entirely offline

## Tech stack

- [React 19](https://react.dev/) with TypeScript
- [Vite](https://vite.dev/) for building and local development
- [Tailwind CSS 4](https://tailwindcss.com/) for styling
- [Framer Motion](https://motion.dev/) for the text decryption animation

## Development

```bash
npm install
npm run dev      # start the dev server
npm run lint     # run eslint
npm run build    # type-check and build to dist/
npm run preview  # preview the production build
```

## Deployment

Pushes to `main` deploy automatically to GitHub Pages via the workflow in `.github/workflows/deploy.yml`. A manual deploy is also available with `npm run deploy` (gh-pages).
